# 🏫 16:9 쉬는 시간 알람 & 수업 안내 디스플레이

교실 TV, 대형 모니터, 빔프로젝터(16:9) 화면에 띄워두고 사용하는 **귀여운 블루톤 쉬는 시간 알람 앱**입니다.  
별도 프로그램 설치 없이 웹 브라우저(Chrome, Edge, Whale 등)에서 즉시 실행됩니다.

---

## 🚀 빠른 시작 방법
1. 폴더 안의 **`실행하기.bat`** 또는 **`index.html`** 파일을 더블 클릭합니다.
2. 브라우저가 열리면 키보드의 **`F11`** 키를 누르거나 우측 상단의 **⛶ (전체화면)** 버튼을 눌러 교실 화면에 꽉 차게 띄웁니다.

---

## ✨ 주요 기능 안내

### 1. 현재 시간 & 쉬는 시간 카운트다운 (좌측)
- **실시간 디지털 시계**: 년/월/일/요일 및 초 단위 실시간 표시
- **쉬는 시간 원형 타이머**: 남은 시간에 따라 부드럽게 줄어드는 비주얼 게이지
- **귀여운 마스코트 고양이**: 쉬는 시간 상황에 맞춰 귀여운 말풍선 대사 출력
- **원클릭 프리셋**: `5분`, `10분`, `15분`, `20분` 버튼으로 즉시 시간 설정
- **타이머 제어**: 시작/일시정지, 🔄 리셋, ➕ 1분 연장 기능

### 2. 수업 관련 미디어 & 공지 허브 (우측)
상단 탭을 클릭하여 즉시 모드를 전환할 수 있습니다:
- 💬 **수업 안내 & 문구 모드**: 주요 준비물 공지, 스트레칭/물 마시기 팁 카드, 선생님 말씀
- 🖼️ **수업 이미지 모드**: 수업 관련 다이어그램, 사진, 귀여운 일러스트를 고해상도로 표시
- 🎬 **수업 영상 모드**: 유튜브 링크나 로컬 비디오(MP4) 파일을 등록하여 수업 사전 학습 영상 상영

### 3. 학교 차임벨 사운드 시스템 (Web Audio)
- 브라우저 자체 합성 음원으로 인터넷 연결이나 외부 파일 없이 맑고 부드러운 종소리가 울립니다.
- **종료 1분 전**: 2음 예비령 ("딩-동") 울림 & 게이지가 긴급 코랄 톤으로 변경
- **쉬는 시간 종료 시**: 한국 학교 전통 4음 딩동댕동 차임벨 울림
- **볼륨 조절 및 음소거**: 상단 🔔 아이콘 또는 설정창에서 언제든 조절 가능

### 4. 간편한 사용자 설정 (우측 상단 ⚙️)
- 수업 교시 및 과목명 변경 (예: `4교시 : 재미있는 수학 시간 📐`)
- 기본 쉬는 시간 길이 변경
- 공지 문구, 이미지 웹 주소 또는 내 컴퓨터 사진 파일 등록
- 유튜브 링크 또는 비디오 파일 등록
- 눈이 편안한 3가지 딥 블루 테마 선택
- **설정 자동 저장**: 브라우저를 닫았다가 다시 열어도 변경한 설정이 유지됩니다 (`localStorage`).

## ⌨️ 편리한 키보드 단축키
- **`Space`**: 타이머 시작 / 일시정지
- **`R`**: 타이머 리셋
- **`F`** 또는 **`F11`**: 전체화면 켜기 / 끄기
- **`M`**: 알람음 음소거 켜기 / 끄기

# 🏫 16:9 쉬는 시간 알람 & 수업 안내 디스플레이 (모던 미니멀 우드 에디션)

교실 TV, 대형 모니터, 빔프로젝터(16:9) 화면에 띄워두고 사용하는 **모던 미니멀 우드톤 쉬는 시간 알람 디스플레이**입니다.  
과도하고 아기자기한 요소를 배제하고, 절제된 딥 월넛 & 오크 원목 프레임과 정교한 기하학적 타이포그래피, 세련된 포커스 & 리프레시 위젯을 적용하여 눈이 편안하고 모던한 수업 환경을 조성합니다.  
별도 프로그램 설치 없이 웹 브라우저(Chrome, Edge, Whale 등)에서 즉시 실행됩니다.

---

## 🚀 빠른 시작 방법
1. 폴더 안의 **`실행하기.bat`** 또는 **`index.html`** 파일을 더블 클릭합니다.
2. 브라우저가 열리면 키보드의 **`F11`** 키를 누르거나 우측 상단의 **⛶ (전체화면)** 버튼을 눌러 교실 화면에 꽉 차게 띄웁니다.

---

## ✨ 주요 기능 안내

### 1. 실시간 시계 & 쉬는 시간 카운트다운 (좌측)
- **모던 디지털 시계**: 년/월/일/요일 및 초 단위 실시간 표시 (세련된 Plus Jakarta Sans & 앰버 골드 악센트)
- **미니멀 원형 다이얼 타이머**: 정교한 12px 웜 우드 그라데이션 링 게이지로 남은 시간을 절제감 있게 표시
- **모던 포커스 & 리프레시 위젯**:
  - 지오메트릭 아키텍처 벡터 모티프 (미니멀 모래시계 & 포커스 코어)
  - 상황별 스마트 가이드 칩 (`스트레칭 및 수분 섭취`, `교재 확인 및 제자리 착석` 등)
  - 실시간 상태 & 다음 목표 표시
- **원클릭 프리셋**: `5분`, `10분`, `15분`, `20분` 버튼으로 즉시 시간 설정
- **타이머 제어**: 시작/일시정지, 🔄 리셋, ➕ 1분 연장 기능

### 2. 수업 관련 미디어 & 공지 허브 (우측)
상단 탭을 클릭하여 즉시 모드를 전환할 수 있습니다:
- 📋 **수업 공지 & 준비 모드**: 핵심 공지사항, 3가지 웰니스 팁 카드 (Hydration, Posture Reset, Eye Care), 수업 안내 메모
- 🖼️ **시각 학습 자료 모드**: 수업 관련 다이어그램, 사진, 고해상도 자료 표시 (웹 링크 또는 내 컴퓨터 사진 파일 등록 가능)
- 🎬 **시청각 영상 모드**: 유튜브 강의 링크나 로컬 비디오(MP4) 파일을 등록하여 수업 사전 학습 영상 상영

### 3. 학교 차임벨 사운드 시스템 (Web Audio)
- 브라우저 자체 합성 음원으로 인터넷 연결이나 외부 파일 없이 맑고 청아한 종소리가 울립니다.
- **종료 1분 전**: 2음 예비령 ("딩-동") 울림 & 게이지가 따뜻한 테라코타 오렌지 톤으로 전환
- **쉬는 시간 종료 시**: 한국 학교 전통 4음 딩동댕동 차임벨 울림
- **볼륨 조절 및 음소거**: 상단 🔔 아이콘 또는 설정창에서 언제든 조절 가능

### 4. 간편한 사용자 설정 (우측 상단 ⚙️)
- 수업 교시 및 과목명 변경 (예: `3교시 : 과학 (Science) 🔬`)
- 기본 쉬는 시간 길이 변경
- 공지 문구, 이미지 웹 주소 또는 내 컴퓨터 사진 파일 등록
- 유튜브 링크 또는 비디오 파일 등록
- **3가지 모던 우드 톤 선택**:
  - `차분한 다크 월넛 (Dark Walnut)`: 깊이 있고 차분한 고급 원목 톤 (기본)
  - `모던 내추럴 오크 (Natural Oak)`: 절제되고 화사한 카라멜 오크 톤
  - `포근한 클래식 티크 (Classic Teak)`: 따뜻한 골든 앰버 티크 톤
- **설정 자동 저장**: 브라우저를 닫았다가 다시 열어도 변경한 설정이 유지됩니다 (`localStorage`).

## ⌨️ 편리한 키보드 단축키
- **`Space`**: 타이머 시작 / 일시정지
- **`R`**: 타이머 리셋
- **`F`** 또는 **`F11`**: 전체화면 켜기 / 끄기
- **`M`**: 알람음 음소거 켜기 / 끄기
